# Mini Library System

Mini project Python CLI yang saya buat untuk melatih dasar Python sebelum mempelajari Object-Oriented Programming (OOP).

## Features

- Mencari buku
- Menambah buku
- Meminjam buku
- Mengembalikan buku

## Concepts Used

- Variables
- List
- Function
- If / Elif / Else
- While Loop
- append()
- remove()
- sort()

## How to Run

```bash
python project_kedua.py
```
