
## 🤖 Machine Learning Projects

This section contains my experiments and projects related to Machine Learning.

### Weekly Sales Prediction

A Machine Learning project that predicts weekly sales using features such as:

- Store
- Holiday information
- Temperature
- Fuel price
- CPI
- Unemployment
- Date-related features

The project includes:

- Data preprocessing
- Missing value checking
- Duplicate data checking
- Date feature engineering
- Linear Regression
- Random Forest Regressor
- Model evaluation using R² Score, MAE, and RMSE

The Random Forest Regressor performed significantly better than the Linear Regression model in this experiment.
